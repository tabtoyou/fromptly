🪶 Fromptly 테스트 페이지

이 페이지에서 Fromptly 확장 프로그램을 테스트해보세요

⚠️ 주의: Fromptly가 설치되고 활성화되어 있는지 확인하세요. 모호한 표현을 입력하면 약 800ms 후 주황색 밑줄이 표시됩니다.

테스트 1: Textarea

아래 textarea에 모호한 표현을 입력해보세요

테스트 2: Input Field

아래 input 필드에 모호한 표현을 입력해보세요

테스트 3: ContentEditable

아래 편집 가능한 영역에 모호한 표현을 입력해보세요

여기에 입력하세요: make it nicer, add more space...

📝 테스트할 모호한 표현들:

  • ✓ make it pop - 시각적 강조 요청
  • ✓ cleaner - 단순화 요청
  • ✓ more balanced - 레이아웃 조정
  • ✓ modern - 스타일 변경
  • ✓ better - 모호한 개선 요청
  • ✓ 깔끔하게 - 한국어 모호 표현
  • ✓ bigger - 크기 조정
  • ✓ more space - 간격 조정
  • ✓ looks weird - 문제 설명
  • ✓ more contrast - 접근성 요청

🔍 디버깅 방법:

  • 1. F12를 눌러 개발자 도구를 엽니다
  • 2. Console 탭을 확인합니다
  • 3. "Fromptly: Extension active" 메시지를 찾습니다
  • 4. 에러 메시지가 있는지 확인합니다
  • 5. 입력 후 800ms 정도 기다립니다 (디바운스)
